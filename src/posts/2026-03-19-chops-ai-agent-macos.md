# Chops: Your AI Agent Skills, Finally Organized on macOS

![Coding setup](https://images.unsplash.com/photo-1461749280684-dccba630e2f6?w=800&auto=format&fit=crop&q=60)

## English

If you work with AI coding assistants like Claude Code, Cursor, Codex, Windsurf, or Amp, you probably know the struggle: each tool has its own set of skills and capabilities, but managing them across platforms can quickly become a chaos. **Chops** arrives to solve exactly that problem.

This open-source macOS application provides a unified interface to browse, edit, and manage AI agent skills across all your favorite coding assistants. Think of it as a central hub where all your AI capabilities converge into one clean, native experience.

### Why Chops Matters

The AI coding assistant landscape has exploded in recent years. Developers now have access to powerful tools that can write code, debug issues, and even refactor entire codebases. However, each tool comes with its own ecosystem of skills, prompts, and configurations. Chops brings sanity to this fragmentation.

Built entirely in Swift and designed specifically for macOS, Chops leverages the platform's native capabilities to deliver a smooth, responsive experience. The app integrates seamlessly with your existing workflow, allowing you to:

- Browse skills from multiple AI assistants in one place
- Edit and customize skills to fit your needs
- Organize skills with tags and categories
- Quick access your most-used capabilities

### Key Features

The application has quickly gained traction in the developer community, amassing over 56 stars on GitHub since its release. Some standout features include:

**Cross-Platform Skill Management**: Import and manage skills from Claude Code, Cursor, Codex, Windsurf, and Amp without switching between multiple interfaces.

**Native macOS Experience**: Built with SwiftUI for a truly native feel, complete with keyboard shortcuts and system integration.

**Easy Editing**: Modify existing skills or create new ones with a user-friendly interface.

The project is actively maintained and welcomes contributions from the community. Whether you're a developer looking to optimize your AI workflow or someone interested in contributing to open-source software, Chops offers a valuable solution to a growing problem.

### Getting Started

Chops is available on GitHub under the MIT license, making it free to use and modify. Simply clone the repository and build the project with Xcode to get started. The documentation provides clear instructions for installation and configuration.
